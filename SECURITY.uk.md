# Політика безпеки та приватності

🇬🇧 [English version](SECURITY.md)

## Персональні дані

Банківські виписки та згенеровані CSV містять персональні фінансові дані: ПІБ, ІПН, IBAN, контрагентів і суми.

- **Ніколи** не комітьте файли з `input/` чи `output/`. Обидві папки ігноруються git, крім заглушок `.gitkeep`.
- **Ніколи** не додавайте реальні виписки, CSV чи незамазані скриншоти до issue, pull request чи обговорень.
- Тести мають використовувати лише синтетичні дані (див. `tests/fakes.py`).
- Якщо ви випадково опублікували персональні дані, одразу видаліть їх і перепишіть історію git (наприклад, через [`git filter-repo`](https://github.com/newren/git-filter-repo)); видалення файлу новим комітом недостатньо.

Парсер працює повністю офлайн і не робить мережевих запитів.

## Підтримувані версії

Виправлення отримує лише останній коміт у `main`.

## Повідомлення про вразливість

Повідомляйте про вразливості приватно через GitHub: **Security → Report a vulnerability** на сторінці репозиторію. Не створюйте публічний issue.

Додайте опис, кроки відтворення на синтетичних даних і наслідки. Відповідь — протягом 14 днів.
