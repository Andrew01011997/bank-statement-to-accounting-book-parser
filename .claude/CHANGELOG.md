## [1.2.0] - 2026-01-16

### Додано
- Підтримка **комісії еквайрингу** для Monobank
- Нова модель `Transaction` з полями:
  - `gross_amount` - повна сума до комісії
  - `commission` - комісія банку
  - `net_amount` - сума після вирахування комісії
- Парсинг комісії з колонки "Деталі операції" (формат: `Загалом X грн. Комісія банку Y грн.`)
- Нові regex паттерни в `constants.py`:
  - `GROSS_AMOUNT_PATTERN` - парсинг суми до комісії
  - `COMMISSION_PATTERN` - парсинг комісії

### Змінено
- CSV тепер має **5 колонок** з заголовками:
  - Час, Дата, Сума, Комісія, Сума з врахуванням комісії
- Контрольна сума перевіряється по колонці "Сума" (gross_amount)
- Оновлено `formatters.py` - нова функція `format_csv_row(transaction)`
- Оновлено `CSVWriter` - додано заголовки CSV
- Оновлено всі парсери для підтримки нової моделі Transaction

## [1.1.0] - 2025-01-15

### Додано
- Підтримка **NovaPay** (`novapay_parser.py`) - небанківський платіжний сервіс
- Новий формат дати без секунд (`dd.mm.yyyy HH:MM`)
- Парсинг сум з комою як десятковим розділювачем (`2 267,80`)
- Контрольна сума NovaPay: "Обороти по кредиту"
- Нові regex паттерни в `constants.py`:
  - `DATETIME_PATTERN_SHORT` - дата+час без секунд
  - `TIME_PATTERN_SHORT` - час без секунд
  - `AMOUNT_PATTERN_COMMA` - сума з комою
  - `NOVAPAY_KEYWORDS` - ключові слова для визначення

### Змінено
- Оновлено `bank_detector.py` для підтримки NovaPay
- Оновлено документацію та README

## [1.0.0] - 2024-12-28

### Додано
- Початкова версія парсера банківських виписок
- Підтримка **ПриватБанку** (`privatbank_parser.py`)
- Підтримка **Монобанку** (`monobank_parser.py`)
- Універсальний парсер для невідомих форматів (`generic_parser.py`)
- Автоматичне визначення типу банку за вмістом PDF (`bank_detector.py`)
- Валідація контрольних сум з виписок
- Фільтрація негативних сум (витрат) - тільки доходи
- Генерація CSV у форматі Книги обліку доходів
- Скрипти запуску для Windows (`run.bat`) та macOS/Linux (`run.sh`)

### Архітектура
- Модульна структура з розділенням на `core/`, `parsers/`, `io/`, `utils/`
- Factory Pattern для створення парсерів (`BankDetector`)
- Абстрактний базовий клас `BaseParser` для розширюваності
- Підтримка різних Unicode знаків мінуса (hyphen, minus sign, en dash)

### Формат виходу
- CSV з 3 колонками: Час, Дата, Сума
- Кодування UTF-8 з BOM для коректного відображення в Excel
- Європейський формат суми (кома як розділювач десятків)
