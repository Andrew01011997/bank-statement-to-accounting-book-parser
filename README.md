# Парсер банківських виписок

Автоматична генерація Книги обліку доходів з банківських виписок ПриватБанку.

## Встановлення

### Windows

1. Встановіть Python 3.7+ (якщо ще не встановлено): https://www.python.org/downloads/
2. Відкрийте командний рядок (CMD) у папці проекту
3. Встановіть залежності:
```bash
pip install -r requirements.txt
```

### macOS

1. Python зазвичай вже встановлений. Перевірте версію:
```bash
python3 --version
```

2. Встановіть залежності:
```bash
pip3 install -r requirements.txt
```

## Використання

### Простий спосіб (рекомендовано)

1. Помістіть PDF файли банківських виписок у папку `input/`
2. Запустіть парсер:

**Windows:**
- Подвійний клік на файлі `run.bat`

**macOS/Linux:**
- Подвійний клік на файлі `run.sh` або виконайте в терміналі:
```bash
./run.sh
```

3. Готові CSV файли з'являться у папці `output/`

### Альтернативний спосіб

**Windows:**
```bash
python parser.py
```

**macOS/Linux:**
```bash
python3 parser.py
```

## Структура проекту

```
kus/
├── input/              # Папка для вхідних PDF файлів
├── output/             # Папка для вихідних CSV файлів
├── example-input/      # Приклади вхідних файлів
├── example-output/     # Приклади вихідних файлів
├── parser.py           # Основний скрипт парсера
├── requirements.txt    # Залежності Python
└── README.md           # Документація
```

## Формат вихідного файлу

CSV файл містить книгу обліку доходів з наступними колонками:
- Дата запису
- Сума, грн
- Сума повернутих коштів
- Скоригована сума
- Вартість безоплатно отриманих товарів
- Сума заборгованості
- Всього

## Примітки

- Назва вихідного CSV файлу відповідає назві вхідного PDF файлу
- CSV файл має кодування UTF-8 з BOM для коректного відображення кирилиці в Excel
- Порядок транзакцій зберігається таким самим, як у виписці
- Парсер обробляє лише доходи (позитивні суми) та ігнорує витрати (від'ємні суми)
- Підтримується формат виписок ПриватБанку
